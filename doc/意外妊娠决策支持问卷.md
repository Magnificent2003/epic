# 意外妊娠决策支持问卷

版本：1.0.0；修订日期：2026-11-08。

供意外妊娠、正在权衡是否继续妊娠的人填写，用于整理本人意愿、健康情况、现实条件与支持需求，作为个人支持报告的信息依据。

填写方法：

- 填写前的报告使用授权、私密填写环境确认与第38题的最终确认是必答流程项；其余业务题和所有补充说明均为选填；可不答、明确选择“不愿回答”、暂停、更正或退出。只有标注允许“不适用”的字段才提供该状态。
- 单选选一项，多选可选多项。各题标明的排他选项应单独选择；“多种感受交织”等不自动排他。第30题有单独的互斥说明，第37题最多选择3项。
- 选择“无”“不清楚”“尚未了解”、未答、明确拒答、不适用和按条件跳过分别记录；留空不会被理解为没有问题，也不会自动补为0。
- 文字补充最多2000字；只填写必要信息，无需提供姓名、联系方式或详细住址。
- 问题按原有主题顺序排列。原稿未提供第18和28题，保留原编号缺口；本版没有新增这两个主问题。
